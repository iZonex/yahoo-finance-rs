# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] as its
code of conduct. The full text is canonical; the points below are a brief
reminder.

We pledge to make participation in our community a harassment-free experience
for everyone. We expect contributors to:

- Be respectful and assume good faith.
- Welcome differing viewpoints and constructive criticism.
- Accept responsibility, apologize, and learn from mistakes.

The following behavior is not acceptable:

- Personal attacks, insulting or derogatory comments, harassment.
- Publishing others' private information without permission.
- Sexualized language or imagery, or unwelcome sexual attention.
- Other conduct which could reasonably be considered inappropriate in a
  professional setting.

## Reporting

Report unacceptable behavior privately via the channel listed in
[SECURITY.md](SECURITY.md). Reports will be reviewed and investigated promptly
and confidentially. Maintainers may take any action they deem appropriate, up
to and including a permanent ban from project spaces.

## Scope

This Code of Conduct applies within all project spaces (issues, pull requests,
discussions, code review) and when an individual is representing the project
in public spaces.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
